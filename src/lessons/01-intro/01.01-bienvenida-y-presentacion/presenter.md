# Notas · 1.1 Bienvenida y presentación

≈ 2 min · sin demo

## 1. Bienvenida y presentación

- Saludo · quién soy · weaaare
- Para quién: HTML y CSS básicos, cero accesibilidad previa
- Promesa: errores frecuentes + cómo se arreglan, en una hora

## 2. Qué es la accesibilidad web

- Cuatro verbos: percibir, entender, recorrer, usar
- 1 de cada 6 personas · y todos, alguna vez (brazo roto, sol, edad)
- Ley Europea de Accesibilidad: junio 2025
- > «Muchas barreras nacen en el código que escribimos. Ahí mismo se arreglan.»

## 3. Cómo funciona cada lección

- Siempre el mismo recorrido: lección → persona → error → solución
- Cada error se puede probar en una página de ejemplo
- > «Siempre empezamos por la persona, no por la técnica.»

## 4. Cómo usar las páginas de ejemplo

- Página web normal · se abre con la barrera
- Barra flotante abajo a la derecha: «Con barrera» / «Con arreglo»
- «Explicación»: qué probar, qué cambia, dónde y por qué, código de las dos versiones
- > «Primero nota la barrera; después mira el arreglo.»
