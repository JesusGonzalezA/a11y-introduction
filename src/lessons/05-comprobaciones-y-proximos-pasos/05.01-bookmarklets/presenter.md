# Notas · 5.1 Inspeccionar el contenido con bookmarklets

≈ 4 min · demo: museo

## 1. Lección

- Bookmarklet = marcador con un script
- Arrastrar a la barra · pulsar sobre la página · recargar para limpiar
- Instalar Headings e Images antes de la sesión

## 2. Situación · Ver la página como Elena

- Elena: encabezados y alt
- > «Los bookmarklets nos prestan los oídos de Elena.»

## 3. Error · Niveles desordenados

- [Ejemplo: abrir «Inspeccionar la exposición con barreras» y pulsar Headings]
- h3 antes que h2: la jerarquía no cuadra
- Recordar 3.1: nivel = relación, no tamaño

## 4. Error · Alt que no describe

- [Pulsar Images]
- Marca verde = existe; no = sirve

## 5. Solución · Corregir, recargar y volver a mirar

- [Ejemplo: «Aplicar arreglo» y repetir]
