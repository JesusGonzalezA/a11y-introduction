# Guion · 5.3 Cómo continuar aprendiendo

## 1. Cómo continuar aprendiendo · 40 s

Hemos partido de una tarea cotidiana: entender una actividad e inscribirnos. Ahora tenemos una primera base para reconocer barreras, organizar contenido, identificar controles, recorrerlos con teclado y comenzar una revisión.

El siguiente paso depende de lo que necesites reforzar. Para estructura y significado, la ruta prevista es HTML Semántico; el enlace verificado se llama HTML Semántico para diseñadores. Para nombres, roles, estados y relaciones, seguimos con Fundamentos de ARIA, que aparece dentro del curso Introducción a ARIA. Conservamos los títulos reales de sus fichas para que puedas reconocerlos al abrirlas.

## 2. Practicar, probar y ampliar las interfaces · 45 s

Para verificar comportamientos, la ruta continúa con Testing de componentes para accesibilidad. La ficha pública enlazada se llama Testing de accesibilidad para desarrolladores. Después podemos aplicar lo aprendido a formularios y navegación; para esta última hay una ficha de ARIA Avanzado: Navegación accesible.

No hemos podido verificar una publicación y URL de curso específico de Formularios. El tutorial de etiquetado de WAI es un recurso de apoyo, no un sustituto presentado como ese curso. Data Display sigue siendo una continuación futura, sin enlace ni fecha confirmados. Las fichas públicas verifican la oferta, no que hayamos probado el contenido de pago.

## 3. Herramientas, ejemplos y continuación · 35 s

Esta última slide reúne los enlaces para volver después: Headings e Images para inspeccionar, FastPass para una primera revisión y las etapas de la actividad en Storybook para practicar. También conserva los cursos de continuación y el apoyo de WAI para formularios, con los límites de disponibilidad indicados.

No abrimos una demo nueva. Puedes volver a una tarea concreta, revisarla, corregir una barrera y comprobar el cambio. Esa práctica combina el significado del contenido, la interacción y las herramientas: ninguna de las tres partes sustituye a las otras.
