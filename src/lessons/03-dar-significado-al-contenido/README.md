# Módulo 3. Dar significado al contenido

**≈ 16 minutos.** Estructura, imágenes, enlaces, botones y campos que se entienden sin verlos.

| Lección | Persona y tarea | Errores → solución | Ejemplo |
| --- | --- | --- | --- |
| [3.1 Estructura de página y orden de lectura](./03.01-estructura-y-orden-de-lectura/README.md) | Elena (lector) busca los ingredientes de una receta | `div` como títulos y zonas, orden invertido → `h1`–`h3`, regiones, HTML en orden | `receta` |
| [3.2 Imágenes, enlaces y controles comprensibles](./03.02-imagenes-enlaces-y-controles/README.md) | Elena lee una noticia; Lucía se suscribe al boletín | `alt` inútil, «Leer más», placeholder, «Aceptar» → `alt` con propósito, enlace descriptivo, `label`, acción en el botón | `noticia` |
